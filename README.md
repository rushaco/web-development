* Components

* Hooks
* Forms and events

* Routing
* Building interactive web applications

### 5. Backend

* Node.js
* Express.js
* REST APIs
* Authentication
* Server-side development

### 6. Database

* MongoDB
* Database design
* CRUD operations
* Connecting applications with databases

### 7. Full-Stack Projects

Projects combining frontend, backend, APIs and databases to build complete web applications.
