This repository contains my HTML practice work while learning the fundamentals of web development.

I created these files to understand and practice different HTML elements, tags, attributes, page structure, links, forms, tables, multimedia, and semantic HTML.

* HTML document structure
* Headings and paragraphs
* Text formatting
* Comments and whitespace
* Links and navigation
* Images
* Lists
* Tables
* Forms
* Semantic HTML tags
* Meta tags
* Audio and video
* Iframes
* Internal and external links
* HTML attributes
